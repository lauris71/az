Clears value at datastore position.

If the element was a large value, the number of data slots occupied the element is returned. The impl is set to NULL but data_idx remains valid after the clear operation. Datablock is not needed because only values can use it and values do not need destruction.

elementsThe datastore elements array

Set uninitialized datastore element.

Stores an instance of the given implementation to the uninitalized space in the datastore. For large values, the data_pos has to be set up to point 16-byte aligned free region in the data buffer. It is the job of the caller to ensure, that there is enough free space to store the value.
