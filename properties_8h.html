void * inst,
AZInterfaceForeachFunc cb,
void * data )

Iterate over all visible interfaces of an instance or type.

Enumerates the interface tree in pre-order: direct interfaces (level 0), then under each its declared sub-interfaces and super-interfaces (increasing levels). The callback receives the resolved interface view (iface_impl/iface_inst; inst locations are NULL for type-level calls). Super-interfaces share the impl/inst of the sub-interface (offset 0). The same interface type may appear multiple times through different paths; the occurrences are distinguished by their locations.

Parameters
implthe implementation (and class) to enumerate
instthe instance (may be NULL for type-level enumeration)
cbthe callback (AZ_OK to continue, positive to stop, negative error)
datauser data passed to the callback
Returns
AZ_OK if the enumeration ran to completion, the callback's positive stop token, or the negative error code

Iterate over all visible properties of an instance or type.

Enumerates the properties in lookup order: own properties, then interface properties (recursively), then the parent class. The callback receives the defining class and the index within it (the property identity - there is no flat props_all), plus the impl/inst location the property is accessed through (the base instance or one of the interface views; inst locations are NULL for type-level calls). A property belongs to an interface iff its impl/inst matches that interface view from az_foreach_interface.

Duplicates are not suppressed: a property reachable by multiple paths is reported once per path, with the respective location.

Parameters
implthe implementation (and class) to enumerate
instthe instance (may be NULL for type-level enumeration)
cbthe callback (AZ_OK to continue, positive to stop, negative error)
datauser data passed to the callback
Returns
AZ_OK if the enumeration ran to completion, the callback's positive stop token, or the negative error code

Get property value by defining class and property index.

This is the most generic method that can retrieve any kind of property given the defining class and the implementation and instance of the type. For class/implementation level properties the instance can be NULL. The normal order of execution is to first call az_lookup_property and, if the property is found, use def_class, impl, inst and index to fetch the property value.

The implementation determines the class and which property definitions can be served:

  • a class implementation (AZ_IMPL_IS_CLASS) provides class and instance storage only - getting class defined property
  • an interface implementation (the class is AZ_CLASS_FROM_IMPL(impl)) additionally provides implementation storage - getting class/impl defined property
Parameters

implthe actual implementation of the instance
instthe actual instance (or NULL for class/implementation level properties)
idproperty index in class
prop_implresult implementation
prop_valresult value
val_sizeresult value size (value is autoboxed if size is bigger)
Returns
AZ_OK or error code

get the index, the containing class and corresponding implementation and instance of a property

Searches class and interface definitions recursively for a property. The order is class->interface[0]->superinterfaces->interface[1]...->superclasses If the index is >= 0, the property definition is def_class->props_self[index]

The class is derived from the implementation (AZ_CLASS_FROM_IMPL): a class implementation searches its own class, an interface implementation searches the interface class. Class-level queries pass the class implementation (&klass->impl) with a NULL instance.

Parameters
impltype implementation (the class implementation for class-level queries)
insttype instance (can be null for class/implementation level queries)
keythe property key
def_classresult: the actual class where the property is defined
sub_implresult: the actual implementation (either impl or sub-implementation, can be null)
sub_instresult: the actual instance (either inst or sub-interface, can be null)
Returns
the property index in def_class or error code
