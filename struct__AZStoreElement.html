Detailed Description

A compact storage element for containers.

A datastore consists of an array of AZStoreElements and data buffer. Values up to 8 bytes are stored directly in store elements, larger values as indices into the data buffer. The data buffer has granularity of 16 bytes and must be aligned to 16 bytes.
