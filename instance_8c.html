Get property value by defining class and property index.

This is the most generic method that can retrieve any kind of property given the defining class and the implementation and instance of the type. For class/implementation level properties the instance can be NULL. The normal order of execution is to first call az_lookup_property and, if the property is found, use def_class, impl, inst and index to fetch the property value.

The implementation determines the class and which property definitions can be served:

  • a class implementation (AZ_IMPL_IS_CLASS) provides class and instance storage only - getting class defined property
  • an interface implementation (the class is AZ_CLASS_FROM_IMPL(impl)) additionally provides implementation storage - getting class/impl defined property
Parameters
def_klassthe class where property is defined
implthe actual implementation of the instance
instthe actual instance (or NULL for class/implementation level properties)
idproperty index in class
prop_implresult implementation
prop_valresult value
val_sizeresult value size (value is autoboxed if size is bigger)
Returns
AZ_OK or error code

const AZImplementation * az_instance_get_interface ( const AZImplementation * impl,
void * inst,
unsigned int if_type,
void ** if_inst )

Get the first interface of given type as naked interface.

The search order is:

  • the instance itself (if it is an interface of right type)
  • all interfaces implemented by given class (self-interfaces)
  • all sub-interfaces implemented by self-interfaces (recursively)
  • all interfaces (first self-interfaces, then sub-interfaces) implemented by parent As the same interface type may be implemented at different places, only the first will be returned. Boxed interfaces and boxed values are transparently delegated.
Parameters
implThe type implementation
instThe type instance
if_typeThe interface type
if_instThe output value for interface instance
Returns
