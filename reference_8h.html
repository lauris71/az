◆ az_reference_try_ref()

ARIKKEI_INLINE unsigned int az_reference_try_ref ( AZReference * ref)

Try to acquire a strong reference (weak->strong promotion primitive).

Succeeds only if the object is alive: the count is brought from n to n+1 atomically, so a concurrent final unref either loses to us (its DEAD claim fails) or has already claimed disposal (we fail). Fails on AZ_REFERENCE_DEAD and on 0 (invalid). On success a strong reference is held (acquire ordering).

In single-threaded builds this is a plain read + ref: a non-NULL weak pointer always refers to a live object there (weak pointers are cleared synchronously during dispose, and nothing can interleave).
