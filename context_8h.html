#define AZ_EXCEPTION_LEVEL   0

The subsystem level that emitted the exception.

Normally the highest-level subsystem should create the (extended) context. Whenever there is an exception, each subsystem level knows whether it was emitted by itself or higher level (and thus has subsystem-specific data set in context) or level below (and thus does not).

◆ az_context

ARIKKEI_THREAD_LOCAL AZContext* az_context
extern

The global exception context.

While the most of az uses error-codes, the global context is needed to pass boundaries between different subsystems (native/az, azo/az). The context is NULL initially and should be ignored if not set.
