◆ az_any_to_string()

int64_t az_any_to_string ( const AZImplementation * impl,
void * inst,
uint8_t * d,
uint64_t d_len )

Fallback to_string method.

Prints "Any" for pure Any, or "Instance of <class name> (<instance pointer>)" for subclasses. The inst should not be NULL, use az_null_to_string for null instances. Writes at most d_len bytes. Unless d == NULL or d_len == 0 the string is terminated with '\0'.

Parameters
implan implementation
instan instance
dthe destination buffer (may be NULL, nothing is written then)
d_lenthe destination buffer length
Returns
the required length of the string (excluding the terminating '\0', may be bigger than d_len)
