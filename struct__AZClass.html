◆ allocator_idx

uint8_t AZClass::allocator_idx

Index into the class allocator table (0 = default malloc/free).

Custom allocators are rare (a single variant for a class subtree at most), so they are kept in a side table instead of a per-class pointer.

◆ default_value

const void* AZClass::default_value

The default value image (AZ_FLAG_HAS_DEFAULT).

Construction copies instance_size bytes from here, replacing the constructor walk for this class and its ancestors (see the flag). Only concrete value types may carry a default value; set it in class_init.

◆ delegate_idx

uint8_t AZClass::delegate_idx

Index into the class delegate table (0 = no delegation).

Delegation is an opt-in, cold-path feature (e.g. AZReferenceOf forwards interface and property queries to the contained type); the delegate holds the rarely used virtuals so they do not grow the class.
