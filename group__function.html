Call a native C function with az arguments.

Marshals the arguments according to the native calling rules (see above) and calls the native function. The native function has to be non-variadic.

Currently implemented for ARM64 (AAPCS64), x86-64 System V (AMD64) and x86-64 Windows (Microsoft x64 calling convention), returns 0 on other architectures.

Parameters
functhe native function pointer
sigthe function signature
ret_implthe returned implementation (may be NULL)
ret_valthe returned value (may be NULL if the return value is not needed)
arg_implsargument implementations
arg_valsargument values
Returns
1 on success, 0 on error
