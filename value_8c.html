convert a value to another type, boxing/unboxing if needed

Boxed values are treated transparently (unboxed at input). Boxed interfaces keep the presented view. Nothing is converted to AZ_TYPE_BOXED_VALUE (a boxed value is a storage detail created when the content does not fit into dst, never a target).
