void * inst,
unsigned int if_type,
void ** if_inst )

Get the first interface of given type as naked interface.

The search order is:

  • the instance itself (if it is an interface of right type)
  • all interfaces implemented by given class (self-interfaces)
  • all sub-interfaces implemented by self-interfaces (recursively)
  • all interfaces (first self-interfaces, then sub-interfaces) implemented by parent As the same interface type may be implemented at different places, only the first will be returned. Boxed interfaces and boxed values are transparently delegated.
Parameters
implThe type implementation
instThe type instance
if_typeThe interface type
if_instThe output value for interface instance
Returns
The implementation of an interface

const AZImplementation * az_instance_get_interface_autobox ( const AZImplementation * impl,
void * inst,
unsigned int if_type,
AZValue * dst )

Get the first interface of given type as a boxed interface handle value, if boxing is possible, otherwise as naked interface.

The destination value receives the interface handle: a boxed interface (AZ_BOXED_INTERFACE_IMPL + owned reference) when a box can own the container lifecycle, or the naked view (interface implementation + borrowed instance). The result may hold a reference and has to be cleared by the caller.

A sub or same interface of a naked interface remains naked The same interface of the boxed interface returns a reference to the same box A subinterface of a boxed interface returns a new box An interface of a value or reference container creates a new box An interface of a plain block container remains naked (caller-managed lifetime)

Parameters
implThe type implementation
instThe type instance
if_typeThe interface type
dstThe destination value for the interface handle (has to be cleared by the caller)
Returns
The implementation stored in dst (AZ_BOXED_INTERFACE_IMPL if boxed), or NULL if there is no such interface
