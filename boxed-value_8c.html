copy a value to a new location, boxing/unboxing if needed

Copy data from initialized src to uninitialized dst. After the operation src will reamin intact. If the source does not fit into size bytes AZBoxedValue is created in dst. If src is AZBoxedValue but the value fits into dst the actual value is copied.
