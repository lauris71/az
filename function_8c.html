unsigned int az_function_signature_is_assignable_to ( const AZFunctionSignature * sig,
const AZFunctionSignature * other,
unsigned int test_ret_val )

Check whether function with given signature is assignable to another.

Requires strict compatibility for both arguments and return value - only subclasses accepted, no implicit conversions. The implementation has to be at least as pure as the slot - a pure function is assignable to a non-pure slot, but not the other way around. A varargs implementation is assignable to a non-varargs slot if its fixed arguments match the leading slot arguments and the remaining slot arguments match the varargs tail type. A fixed implementation is never assignable to a varargs slot (the slot allows argument counts the implementation cannot serve).

Parameters
sigThe function signature (implementation)
otherThe other function signature (slot)
test_ret_valWhether to test return value also
Returns
1 if assignable, 0 otherwise
