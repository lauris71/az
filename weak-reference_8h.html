#define AZ_TYPE_WEAK_REFERENCE   az_weak_reference_get_type ()

Weak reference to an active object.

Stores a pointer to an AZActivbeObject without claiming reference. The pointer is cleared when the object is destroyed (in dispose handler).

Zero reference can be safely used and destroyed without init/finalize cascade

◆ az_weak_reference_acquire()

AZActiveObject * az_weak_reference_acquire ( AZWeakReference * ref)

Acquire a strong reference to the weakly referenced object.

Weak->strong promotion (docs/mt-reference-locking.md §7): atomically acquires a counted reference if the object is still alive. This is the only safe way to extract the pointer in multi-threaded builds; do not read ref->ptr directly.

Returns
the object with an owned strong reference (unref when done), or NULL if the object has died

◆ az_weak_reference_set()

void az_weak_reference_set ( AZWeakReference * ref,
AZActiveObject * object )

Set the weak reference to an object.

The caller must hold a strong reference to the object for the duration of the call (so it cannot die between the pointer store and the listener registration). Only az_weak_reference_acquire is safe against concurrent object death; set/clear on the SAME weak reference from multiple threads require external synchronization.

References az_active_object_add_listener(), az_weak_reference_clear(), and weak_reference_event_vec.
